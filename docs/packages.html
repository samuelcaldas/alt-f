Additional Packages & Extensions

Install, update, and manage supplemental disk-installed packages directly from the web interface.

Package Ecosystem Overview

In addition to the software pre-installed in the firmware image, Alt-F provides a modular package management system based on ipkg. Packages can be installed on hard disk partitions or to the extra flash partition (UBIFS on NAND flash models).

Through the Packages section in the web interface, you can manage:

  • Alt-F Packages: Official pre-compiled packages maintained specifically for Alt-F uClibc-ng ARM architecture.
  • Entware / Entware-ng: Modern embedded package feed providing hundreds of command-line tools, servers, and interpreters.
  • FFP (Fonz Fun Plug): Legacy package repository for DNS-323 and DNS-320 community extensions.
  • Debian Chroot: Run a full Debian distribution under Alt-F for advanced command-line workloads.

Featured Add-on Packages

Transmission BitTorrent

Full-featured BitTorrent client with remote web interface, bandwidth scheduling, and blocklist support.

MiniDLNA Media Server

Lightweight UPnP/DLNA server serving movies, music, and photos to Smart TVs, consoles, and mobile apps.

Aria2 Multi-Protocol Downloader

High-speed download utility supporting HTTP/HTTPS, FTP, BitTorrent, and Metalink with WebUI frontend integration.

aMule eDonkey/KAD Client

P2P file sharing client with web interface for eDonkey2000 and Kademlia network downloads.

NZBGet & SABnzbd

High-efficiency Usenet binary downloaders with automatic unpack, parity verification, and web management.

Lighttpd Web Server

Fast, memory-efficient web server supporting FastCGI, PHP, and custom website hosting.

MySQL / MariaDB

Relational database management server for hosting database-backed web applications locally.

Shell In A Box

Web-based terminal emulator allowing secure SSH shell access directly inside your web browser.

Managing Packages from the Web UI

  1. Open the web administration interface and navigate to Packages → Alt-F.
  2. Select the storage destination where packages should be installed (e.g., /mnt/sda2 or flash).
  3. Click UpdatePackageList to fetch the latest index from the package feed.
  4. Click Install next to the desired package. Dependencies are resolved and installed automatically.
  5. Services that provide a web interface or daemon automatically add a corresponding configuration page under the web menu.

Offline Package Installation

If your NAS has no direct internet connection, download the .ipk packages to your computer, copy them to a shared folder on the NAS, and install them via the web interface or via ipkg install /path/to/package.ipk in the shell.
