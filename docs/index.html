Alt-F

A free and open source alternative firmware for the D-Link DNS-320/320L/321/323/325/327L and DNR-322L Network Attached Storage devices.

GitHub Repository Installation Guide Download Releases

About Alt-F

Alt-F provides a modern Linux operating system for popular ARM-based D-Link network storage hardware, freeing your device from outdated vendor software restrictions.

Alt-F has Samba and NFS; supports ext2, ext3, ext4, BTRFS, VFAT, NTFS and ISO9660 filesystems; RAID 0, 1, 5 (with an external USB disk) and JBOD; supports drives up to 8TB+; provides rsync, FTP, SFTP, FTPS, SSH, LPD printing, integrated DNS and DHCP servers, dynamic DNS, fan and LED regulation, clean power up and down... and much more.

Alt-F also features a comprehensive, modernized web administration interface, allowing you to configure storage, networking, and services without needing shell commands.

Key Capabilities

Advanced Storage & Filesystems

Full support for ext2/3/4, BTRFS, FAT32, exFAT, and NTFS-3G. Soft-RAID (RAID0, RAID1, RAID5) with non-destructive bidirectional conversion between standard filesystems and RAID1.

Networking & File Sharing

Samba 4 (SMB2/SMB3) with Microsoft WS-Discovery daemon (WSDD2), native NFS v3/v4, FTPS, SFTP, OpenSSH, Dropbear, rsync, and AFP Time Machine support.

Extensible Packages

In addition to builtin software, Alt-F supports packages on disk or flash through its ipkg manager, as well as full compatibility with Entware-ng and FFP (Fonz Fun Plug).

Lightweight Web Administration

Modern, responsive administration interface running purely on BusyBox httpd with POSIX shell CGI pairs. Consumes no heavy background daemon memory.

Monitoring & Power Control

S.M.A.R.T. drive health monitoring, temperature-guided fan speeds, power button shutdown controls, UPS monitoring (NUT, apcupsd), and email alerts via msmtp.

Media & Downloads

Built-in or downloadable support for MiniDLNA, Transmission (BitTorrent), Aria2, aMule, NZBGet, Lighttpd, and MySQL/MariaDB.

Hardware Support

Alt-F has been developed and tested on multiple hardware boards and revisions. The root filesystem runs directly from flash (SquashFS + UBIFS) to maximize available RAM:

DNS-320 Rev A1, A2, B1, B2 Marvell Kirkwood 88F6281 / 88F6702 (ARMv5TEJ) 128MB RAM / 128MB NAND Supported & Tested
DNS-320L Rev A1, A2, A3 Marvell Kirkwood 88F6702 (ARMv5TEJ @ 1.0 GHz) 256MB RAM / 128MB NAND Supported & Tested
DNS-321 Rev A1, A2 Marvell Orion 88F5182 (ARMv5TEJ @ 500 MHz) 64MB RAM / 8MB NOR Supported (Compat pkg)
DNS-323 Rev A1, B1, C1 Marvell Orion 88F5181/88F5182 (ARMv5TEJ @ 500 MHz) 64MB RAM / 8MB NOR Supported & Tested
DNS-325 Rev A1, A2 Marvell Kirkwood 88F6281 (ARMv5TEJ @ 1.2 GHz) 256MB RAM / 128MB NAND Supported & Tested
DNS-327L Rev A1 Marvell Armada 370 88F6707 (ARMv7 @ 1.2 GHz) 512MB RAM / 128MB NAND Supported & Tested
DNR-322L Rev A1 Marvell Kirkwood 88F6281 (Identical to DNS-320 Rev A) 128MB RAM / 128MB NAND Supported & Tested
