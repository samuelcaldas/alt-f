Modernized User Interface

The Alt-F web administration interface allows full control over your storage device without touching the command line. The interface has been modernized to eliminate legacy multi-frame navigation, providing clean HTML5 landmarks, mobile-friendly responsive viewports, and sub-100 KiB page rendering budget:

System Status

Real-time overview of CPU load, memory utilization, mounted filesystems, network interfaces, temperatures, and uptime.

Disk Utilities & Partitioning

Graphical partition manager supporting GPT and MBR schemes, filesystem formatting (ext2/3/4, Btrfs, FAT, NTFS), and filesystem integrity checks.

RAID Array Management

Wizard and manual controls for configuring RAID0, RAID1, and RAID5 arrays, monitoring resync progress, and performing non-destructive migrations.

Users, Groups & Permissions

Comprehensive user account creation, group memberships, and granular read/write filesystem access control.

Network File Sharing

Samba 4 share manager, NFS export controls, FTP server settings, and user quotas.

Services & Daemons

Start, stop, and configure system daemons including SSH, Rsync, Dnsmasq, Inadyn, Avahi, Cron, and Stunnel.
