Installation, Upgrades & Recovery

Complete guide to flashing Alt-F, troubleshooting first boot, managing settings, and restoring stock firmware.

1. Flashing Alt-F for the First Time

Alt-F is packaged as a standard firmware update file (.bin) that can be applied directly using the vendor's web administration interface:

  1. Reboot the NAS: Reboot the device prior to upgrading to ensure all services are stopped and RAM is unfragmented.
  2. Disable FFP (Fonz Fun Plug): If you have ffp installed on a hard disk, rename the ffp directory to ffp-orig so its scripts do not execute automatically during first boot.
  3. Identify Device Revision: Inspect the label on the bottom of the device to find its exact model and hardware revision level (e.g., DNS-320L Rev A3).
  4. Select the Matching Firmware File: Choose the appropriate .bin file:
    • DNS-320 Rev A1/A2 → Alt-F-*-DNS-320-rev-Ax.bin
    • DNS-320 Rev B1/B2 → Alt-F-*-DNS-320-rev-Bx.bin
    • DNS-320L Rev A1/A2/A3 → Alt-F-*-DNS-320L-rev-Ax.bin
    • DNS-321 Rev A1/A2 → Alt-F-*-DNS-321-rev-Ax.bin
    • DNS-323 Rev A1/B1/C1 → Alt-F-*-DNS-323-rev-AxBxCx.bin
    • DNS-325 Rev A1/A2 → Alt-F-*-DNS-325-rev-Ax.bin
    • DNS-327L Rev A1 → Alt-F-*-DNS-327L-rev-Ax.bin
  5. Flash through Stock UI: In the stock web GUI, navigate to the Firmware Upgrade page, select the firmware file, and click apply.
  6. Wait for Reboot & Clear Cache: Wait for the flashing procedure to finish and the device to restart. Clear your browser cache or open a private window.

Flashing Precaution

Never power off the device during the flashing process. Ensure you are flashing the binary matching your exact hardware revision.

2. Diagnosing First Boot & LED Behavior

Blue Power LED Blinking Slowly (Heartbeat Rate)

The blue power LED pulses with a slow, regular heartbeat while disk LEDs flash randomly. This is normal behavior: it indicates that fsck is checking your hard drive filesystems following an unclean shutdown (which is standard when restarting from vendor firmware).

Do not interrupt the device. Checking a large disk can take 10 to 30 minutes. Once complete, the power LED turns solid blue and services start.

Power Button Recovery Functions

If you cannot access the web interface and need to safely interact with the NAS, press and hold the front power button:

  • After 3 seconds: Right amber disk LED starts flashing → Releasing the button now initiates an orderly reboot.
  • After 6 seconds: Left amber disk LED starts flashing → Releasing the button now initiates an orderly system shutdown.
  • After 9 seconds: LEDs stop flashing → Cancel without taking action.

Locating Your Device on the Network

Alt-F resolves its IP address using the following priority:

  1. Kernel command-line settings (if configured).
  2. Saved Alt-F flash settings in /etc/settings.
  3. Stock firmware settings (if a static IP was previously configured in the vendor GUI).
  4. DHCP client request to your local router.
  5. Fallback link-local IP search in the range 192.168.1.254 down to 192.168.1.240.

3. Saving Settings to Flash

Alt-F runs with an in-memory/compressed root filesystem. When you make configuration changes (users, passwords, network shares, daemon settings):

  1. Navigate to System → Settings in the web menu.
  2. Click Save Settings to commit active configuration files to non-volatile flash memory (/etc/settings).
  3. You can also click Download in the "Computer Disk" section to download a complete backup archive of your settings.

4. Restoring Stock Firmware (Downgrading)

Alt-F's firmware flashing utility allows flashing official D-Link stock firmware binaries directly:

  1. Download the official D-Link stock firmware .bin file for your device from D-Link support.
  2. In Alt-F, navigate to System → Firmware.
  3. Select the vendor .bin file and apply the upgrade.
  4. After rebooting, your device returns to the factory D-Link software.
