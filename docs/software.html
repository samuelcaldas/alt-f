Software Built In the Firmware

Comprehensive inventory of core daemons, networking tools, storage utilities, and system services pre-installed in Alt-F.

Storage & Filesystem Utilities

Alt-F includes kernel modules and user-space binaries to support modern storage workflows:

Filesystem Tools

Full support for e2fsprogs (ext2, ext3, ext4 formatting and repair), btrfs-progs, dosfstools (FAT/VFAT), exfatprogs, and read/write NTFS via ntfs-3g.

Soft-RAID Management (mdadm)

Configures JBOD, RAID0, RAID1, and RAID5 arrays. Supports online array assembly, degraded rebuilding, and non-destructive conversion between standard filesystems and RAID1.

Partitioning (gptfdisk / sgdisk)

Native GPT support for drives up to 8TB+ and beyond. Includes sfdisk and fdisk for MBR disk compatibility.

Logical Volumes & Encryption

Logical Volume Manager 2 (LVM2) tools for dynamic volume resizing. Block device encryption with LUKS via cryptsetup.

Disk Quotas (quota-tools)

User and group filesystem storage quotas can be enforced across shared network volumes.

Remote Filesystems

Automated mounting of remote CIFS/SMB shares (cifs-utils) and NFS shares (nfs-utils).

Networking & File Sharing

Samba 4 (SMB2 & SMB3)

High-performance Windows file sharing with support for modern SMB2 and SMB3 dialects. Features guest access, user permissions, and home folders.

WSDD2 (WS-Discovery Daemon)

Enables Windows 10 and Windows 11 clients to automatically discover the NAS under "Network" without legacy NetBIOS or SMBv1.

NFS v3 & v4 Server

Enterprise Unix/Linux file sharing using nfs-utils and portmap, with granular export permissions.

FTP & FTPS (vsftpd)

Secure, lightweight FTP server with SSL/TLS encryption, anonymous access, and virtual chroot directories.

Secure Shell (SSH & SFTP)

Remote access through OpenSSH and Dropbear. Includes the sftp-server subsystem for encrypted file transfers.

RSYNC Daemon

Fast remote delta synchronization for automated backups between NAS devices or remote servers.

System Services & Infrastructure

Service / Daemon Package Description
DNS & DHCP Server dnsmasq Lightweight local caching DNS proxy and local DHCP server.
Dynamic DNS inadyn-mt Automatic IP address updater supporting DynDNS, No-IP, FreeDNS, and custom DDNS providers.
mDNS / Zeroconf avahi Bonjour/Zeroconf service discovery for Apple and Linux networks.
Time Synchronization ntp Network Time Protocol client and server maintaining accurate RTC time.
SSL Wrapper stunnel Universal SSL encryption wrapper for securing plain-text services.
Certificate Management certs Generates self-signed root CAs and manages Let's Encrypt certificates.
S.M.A.R.T. Health smartmontools Monitors disk temperatures, self-test results, and sends warning emails upon reallocated sectors.
Email Alerts msmtp Lightweight SMTP client forwarding system notifications and disk alerts to your email.
UPS Monitoring apcupsd / nut Communicates with USB/network Uninterruptible Power Supplies for orderly shutdown during outages.
LPD Printing lpd Turns USB-attached printers into shared network printers for Windows and Linux.
Web Administration BusyBox httpd Lightweight HTTP server running the responsive administrative web UI.
